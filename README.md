# 桌游计时器 Board Game Clock

Board game clock for 1–6 players, for phone and tablet. 中英双语。

**Open:** https://clarkckl223.github.io/game-clock/

- 7 modes: absolute, Fischer, byo-yomi, Canadian, Bronstein, simple delay, per-turn
- Layouts: solo, 2-player split, list / ring for 3–6
- Turn order: reorder, skip, pick next; handicap time; 16 colours + custom
- Timeout: lose / go negative / alert only
- Game summary, history saved on device, CSV download, copy as text
- Works offline after first visit; Add to Home screen to use as an app
